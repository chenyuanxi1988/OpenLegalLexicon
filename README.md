# OpenLegalLexicon

**一个以中英文法律词语和法律词组为核心的开源词库。**

这个仓库现在只做一件事：持续扩充、校正和整理高质量的中英文法律术语、固定搭配和实务表达。

此前已经开发的 Anki、Rime、ASR、复杂 CI、证据抓取流水线、测试和报告系统不再是主仓库内容。它们的历史版本完整保存在归档分支：

- `archive/pre-content-first-simplification-20260928`

## 当前目标

**先把词做多、做准、做实用。**

不再优先开发软件功能。未来每一轮开发应主要产出新的法律词语/词组，尤其是律师实际会阅读、书写、检索和口述的表达。

首版内容目标：

1. 核心编审词条达到 **2,000 条**；
2. 主要法律领域都有成体系的中英文术语和固定搭配，而不是零散单词；
3. 对容易误译、跨法域不完全对应的词建立清楚的译法说明；
4. 每条核心词尽量保留法律语境、法域和来源依据；
5. 达到 2,000 条后再评估是否继续扩展到 5,000 条及以上。

1. 公司治理、证券、并购与投融资
2. 合同与商业交易
3. 民事诉讼、仲裁与执行
4. 知识产权
5. 数据、隐私、网络安全与 AI
6. 劳动雇佣
7. 刑事、调查与企业合规
8. 税务、海关、国际贸易
9. 跨境投资、外商投资与制裁
10. 金融、破产、房地产及其他律师实务领域

## 词条原则

优先收录：

- 法律术语，而不是普通英语单词；
- 律师实际使用的法律词组和固定搭配；
- 程序动作，例如“申请财产保全”“提出管辖权异议”；
- 交易表达，例如“交割先决条件”“陈述与保证”；
- 法律角色、机构、法规、条约和常用缩写；
- 容易发生中英误译或跨法域混淆的表达。

对于英文译法：

- 不把项目释译冒充官方译文；
- 不因字面相似就宣称中国法与英美法概念完全等同；
- 有多种常用译法时可以并存，并写明使用语境；
- 准确和实务自然度优先于“看起来像直译”。

## 参考资料

除了法律法规和公开术语来源，本项目可以参考专业法律词典、教材和用户提供的资料来发现候选词、比较译法和发现误译风险，但**不整本复制受版权保护的词典释义**。
