# OpenLegalLexicon

面向语音识别与智能输入的开放中英文法律语言资源库。

An open Chinese–English legal language resource for speech recognition and intelligent text input.

## 项目状态

项目目前处于设计和文档初始化阶段。第一阶段先确定分类、数据结构、来源规则和评测方法，再逐步收录词条。下文列出的数据包、工具和集成功能均为规划，尚未提供可运行的软件或发布版词库。

开发顺序与验收标准见 [DEVELOPMENT_PLAN.md](DEVELOPMENT_PLAN.md)。

## 为什么做这个项目

法律工作中的语音输入经常混合中文、英文法律术语、缩写、机构名称、法规简称和法条编号。单纯的纯文本热词表难以表示法域差异、不同读法、真实别名、常见误识别和适用场景。

OpenLegalLexicon 希望维护一套可追溯、可按需组合、可转换为不同引擎输入格式的公共资源，让词库质量可以通过实际识别效果来检验。

## 设计原则

- **中英混合优先**：覆盖中文句子中的英文术语、逐字母缩写和混合读法。
- **保留法域与语境**：同名术语不自动视为同一概念，跨法域译法不默认等价。
- **按需加载**：组合核心库、业务领域包和法域包，避免一次注入全部词条。
- **源数据与导出分离**：结构化数据作为唯一维护来源，纯文本热词表作为构建产物。
- **来源可追溯**：记录出处、版本、许可、审核状态和更新时间。
- **以评测支持修改**：关注专业术语召回率，同时检查误替换和通用语音回归。

## 资源范围

| 模块 | 规划内容 |
| --- | --- |
| 核心词库 | 通用法律概念、法律关系、责任与程序等基础术语 |
| 业务领域 | 公司、合同、并购、金融、基金、资本市场、知识产权、数据隐私、AI、竞争、劳动、税务、贸易与争议解决等 |
| 法域 | 中国大陆、香港、新加坡、美国、英国、欧盟等；记录适用范围与当地表达 |
| 法律文件与动作 | 文件类型、文件结构、程序动作、交易动作和常用法律表达 |
| 机构与法规 | 公开机构名称、法规名称、简称及名称变更记录 |
| 法律英语与缩写 | 英文、拉丁语、缩写展开形式、不同读法与中英混输形式 |
| 语音混淆集 | 正确术语、实测误识别、触发语境、反例和禁止替换条件 |
| 规范化规则 | 金额、数字、日期、法条、合同条款和案号的书面格式 |
| 评测集 | 可公开分发的法律口述、混合语言、易混淆及普通语音样本 |

公共仓库仅接收适合公开分发的内容。个人习惯、客户、非公开案件和项目词表由使用者在本地叠加，不作为公共贡献上传。

```text
公共核心库 + 业务领域包 + 法域包
                ↓
         用户本地私有词库
                ↓
         当前任务临时词库
                ↓
       筛选、排序与引擎适配
```

## 数据模型草案

拟采用 UTF-8 YAML 维护源数据，以 JSON Schema 校验，按需导出 JSONL、TSV 和引擎专用格式。最终字段规范将在第一阶段确定。

| 字段组 | 主要信息 |
| --- | --- |
| 身份与版本 | 稳定 `id`、`schema_version`、状态、更新记录 |
| 表达 | 中文和英文规范形式、语言标签、真实别名、缩写及展开形式 |
| 概念与分类 | 概念关联、业务领域、法域、术语类型、适用语境 |
| 双语关系 | 对应表达、关系类型、法域、来源及审核状态；允许一对多与暂无对应 |
| 发音 | 拼音或音标、缩写读法、语言、读音变体及证据 |
| 语音信息 | 经验证的误识别、混淆对象、适用条件、反例和引擎版本 |
| 排序信息 | 优先级；实测频率的语料与统计口径；引擎专用权重配置 |
| 来源 | 来源标识、链接、版本或日期、许可、署名和再分发审核状态 |

真实别名与 ASR 错误形式分开维护。误识别记录不会自动变成全局替换规则。频率缺失时保留未知，不把主观优先级标记为实测频率；不同模型的权重也不直接互换。

## 规划中的使用方式

1. 选择语言、法域和业务领域。
2. 合并公开词包，保留同形异义关系，过滤过时或未审核的数据。
3. 根据当前语境和引擎限制选择小规模候选集。
4. 在本地叠加私有词库，再导出引擎可接受的格式。
5. 对比启用前后的识别结果，并记录模型、参数和数据版本。

拟研究 Qwen3-ASR、Whisper、FunASR 和输入法词库适配。各引擎具体支持的上下文、提示或热词机制需按所用版本验证，本项目尚未宣称兼容其中任何一个引擎。

## 评测与质量

规划报告中文 CER、英文 WER、法律术语 precision / recall / F1、法律实体错误率、误替换率、时延和资源开销。中英混合样本将明确分词、标点及大小写处理规则。

每次实验至少保留无词库基线，并加入不包含目标热词的负样本，检验是否因为词库偏置而引入错误。开发集与最终测试集分开；规范化效果与 ASR 效果分别报告。
