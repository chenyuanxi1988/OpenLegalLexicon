# 中国大陆核心领域扩充：官方来源基线（2026-09-12）

本文件记录四批中国大陆核心学习层使用的官方文本版本与来源，并保留后续更新时需要防止的版本错误。它不是“词条数量完成度”证明；任何释义和英文释译都必须继续绑定具体法条并保留审核状态。

## 使用原则

1. 只把法律、行政法规正文作为法条证据；网页导航、编辑说明、配图和第三方英文译文不进入数据集。
2. 中文释义、学习提示和英文译法由项目原创编写并标记 `project_authored` / AI 辅助编辑，不冒充官方译文或律师人工审定。
3. 每个新增词条必须指向具体法条；若一个概念跨多部法律，以最直接规范依据为主。
4. 本文件记录 2026-09-12 的核验状态；后续更新仍需检查网页、法律修订和条文编号变化。
5. 法条转载和许可处理遵循 `DATA_LICENSE.md`；不因法律正文的著作权规则推定整个政府网页可自由复制。

## 当前实施状态

行政/劳动、税务/贸易、刑事三个后续领域批次均已完成“完整文本抓取 → 基础条文序列检查 → 重点条文证据 → 原创核心词条 → schema/单测 → 真实 Anki/Rime → GitHub CI → 自动下载版”闭环。四批中国大陆核心学习层共 218 条。

下一阶段不再继续盲目追求核心词条数量，而是转向 2,730 条来源参考层的高价值编审与覆盖审计；自动分类只用于生成候选，不冒充人工法律审核。
