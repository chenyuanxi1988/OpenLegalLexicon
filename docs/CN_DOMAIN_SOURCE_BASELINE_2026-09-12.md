# 中国大陆核心领域扩充：官方来源基线（2026-09-12）

本文件为下一批 `oll-cn-core` 编审固定官方文本版本。目的不是把网页抓取数量当成词典完成度，而是在写任何释义和英文释译之前，先确定当前适用的法律版本、官方出处和需要重点防止的版本错误。

## 使用原则

1. 只把法律、行政法规的正文作为法条证据；网页导航、编辑说明、配图和第三方英文译文不进入数据集。
2. 中文释义、学习提示和英文译法继续由项目原创编写并标记 `project_authored` / AI 辅助编辑，不冒充官方译文或律师人工审定。
3. 每个新增词条必须指向具体法条；若一个概念跨多部法律，以最直接的规范依据为主，并在需要时增加关系或补充证据。
4. 本文件记录的是 2026-09-12 核验到的来源基线。正式入库时仍要重新检查页面是否更新、法律是否修订以及条文编号是否变化。
5. 法条转载和许可处理继续遵循仓库 `DATA_LICENSE.md` 已建立的规则；不因为法条本身的著作权处理而推定整个政府网页均可自由复制。

## 下一步实施顺序

1. 先做行政处罚/行政复议和劳动合同两个子批次；它们的官方全文和版本链已经清楚，适合作为下一批可验证词条。
2. 税务子批次使用已经生效的增值税法和关税法，不再沿用条例时代的术语定义。
3. 贸易子批次必须以 2025 年第二次修订、2026-03-01 起施行的对外贸易法为唯一当前基线。
4. 刑事子批次先解决“现行刑法合并文本 + 修正案十二”的版本整合，再写核心释义，避免引用过期条文。
5. 每个子批次入库后继续执行 schema 验证、证据比对、单元测试、核心/完整 Anki 真导入、Rime 查询与 GitHub CI；只有远端 CI 和自动生成产物完成后才算该批发布闭环。
