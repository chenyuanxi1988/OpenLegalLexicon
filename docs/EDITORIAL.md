# 核心术语编审与法条证据

核心学习层目前含 **183 个**中国大陆法律语境词条，均标记 `evidence_linked`：首批 99 条覆盖民商、隐私、竞争和知识产权等领域，第二批 38 条覆盖行政处罚、行政复议和劳动合同，第三批 46 条覆盖增值税、关税、对外贸易及贸易救济。`evidence_linked` 表示释义和法域已对应到具体法条；不表示法律专家审核，也不将英文标为官方正式译文。词条由 Codex 辅助编写，署名及审核状态可逐条查看。

## 两个数据层

- 来源参考层保留两套官方双语表的 2,730 条来源对应。来源原文不静默改译，未经核实的法域留空。
- 核心学习层采用多个独立 `editorial_seed` 快照，保留稳定 ID、中文释义、译法说明、学习提示及关系。英文为项目释译；即使中文同形，也不自动合并不同法域或来源的词条。

`--profile learning` 筛选有释义与法条证据的词条。默认参考版同时包含两层，完整保留审核状态。简繁转换仅转换文字形式；中国大陆术语的繁体形式不因此变成台湾或香港法律术语。

- 反倾销、反补贴和保障措施分别保留各自触发要件，不把三者都简化为泛化的“进口保护措施”。
- 第八十二条的“单独关税区”只作为本法适用范围边界记录，不根据该条自行推定具体地区名单。

## 编辑与复核

1. 新的原创批次建立独立 `data/snapshots/oll-cn-*.jsonl`，无需改写已发布批次；稳定 ID 表示固定概念记录，不因释义或拼写修订改变。
2. 释义、法域和学习提示分别声明 `evidence.supports`，以 `document_id` 与 `articles` 指向 `data/evidence/laws.json` 或 `data/evidence/laws-*.json` 中实际存在的法条。
3. 对新版本法条先登记官方 HTTPS 目标，保存公开原始 HTML 到独立缓存，记录获取日期及摘要，完整抽取并审查变化后再更新证据。不能只改条号而沿用旧释义。
4. 若引入新的资料或译文，先独立核验许可。法律中文原文的地位，不证明第三方译文可再分发。
5. 更新来源快照 SHA-256 和条目数，运行校验、单元测试与构建；核心下载版数量测试按全部 `editorial_seed` 合计计算，不把任何单批条目数写死为永久上限。
6. 提交源码后由 CI 实际运行 schema、单元测试、可复现构建、Rime 编译查询以及 Anki 完整版/核心版真实导入与重复导入；只有远端运行和自动生成文件闭环后才记录为已发布。

离线核对已固定的 HTML 与证据，可使用：

```sh
python tools/verify_legal_sources.py --cache /path/to/legal-html --out build/legal-evidence-check.json
```

也可用多个 `--document-id` 只验证一个新批次。工具不联网、不自动覆盖已批准的证据，原 HTML 摘要改变时停止并要求审查。输出只证明抽取一致性，不证明英文准确或法律适用结论。

## 已处理的易混关系与制度边界

首批已记录法人／法定代表人、去标识化／匿名化、时效中止／中断、债权转让／债务转移、要约／要约邀请、一般保证／连带责任保证、忠实／勤勉义务、控股股东／实际控制人、所有权／用益物权、抵押权／动产质权、过错／无过错侵权责任等关系。

第二批把行政复议中止／终止、行政复议机关／机构、劳动合同解除／终止、竞业限制补偿／劳动合同法定经济补偿等制度边界写入学习提示。第三批重点把税率、计税、关税税率类别和三类贸易救济措施的区别写入释义与学习提示。关系字段仍要求有明确法条支持，不为增加图边数量而机械连接。

核心层仍不是完整法律课程；下一批优先处理包含刑法修正案（十二）的现行刑法证据和刑事核心词条，来源参考层的分类、法域和译义复核也继续保留为待办。
