# 核心术语编审与法条证据

首批核心层含 99 个中国大陆法律语境词条，标记 `evidence_linked`。这表示释义和法域已对应到具体法条；不表示法律专家审核，也不将英文标为官方正式译文。词条由 Codex 辅助编写，署名及审核状态可逐条查看。

## 两个数据层

- 来源参考层保留两套官方双语表的 2,730 条来源对应。来源原文不静默改译，未经核实的法域留空。
- 核心学习层保留独立稳定 ID、中文释义、译法说明、学习提示及关系。英文为项目释译；即使中文同形，也不自动合并不同法域或来源的词条。

`--profile learning` 筛选有释义与法条证据的词条。默认参考版同时包含两层，完整保留审核状态。简繁转换仅转换文字形式；中国大陆术语的繁体形式不因此变成台湾或香港法律术语。

## 编辑与复核

1. 修改 `data/snapshots/oll-cn-core-2026-09-12.jsonl` 中的项目词条；ID 表示固定概念记录，不因释义或拼写修订改变。
2. 释义、法域和学习提示分别声明 `evidence.supports`，以 document_id 与 articles 指向 `data/evidence/laws.json` 中实际存在的法条。
3. 对新版本法条保存公开原始 HTML 到独立缓存，记录获取日期及摘要，审查变化后再更新证据。不能只改条号而沿用旧释义。
4. 若引入新的资料或译文，先独立核验许可。法律中文原文的地位，不证明第三方译文可再分发。
5. 更新来源快照 SHA-256 和条目数，运行校验、单元测试与构建；提交源码后由 CI 生成下载版。

离线核对已固定的 HTML 与 101 条证据：

```sh
python tools/verify_legal_sources.py --cache /path/to/legal-html --out build/legal-evidence-check.json
```

缓存文件名为 `civil-code.html`、`company-law.html`、`pipl.html`、`anti-monopoly.html`、`copyright.html`；对应 URL 见证据登记。工具不联网、不自动覆盖已批准的证据，原 HTML 摘要改变时停止并要求审查。输出只证明抽取一致性，不证明英文准确或法律适用结论。

## 已处理的易混关系

法人／法定代表人、去标识化／匿名化、时效中止／中断、债权转让／债务转移、要约／要约邀请、一般保证／连带责任保证、忠实／勤勉义务、控股股东／实际控制人、所有权／用益物权、抵押权／动产质权、过错／无过错侵权责任。共 11 组、22 条有方向的关系。

首批不是完整法律课程；刑事、行政、劳动、税务、贸易等领域的证据型释义仍需扩展，来源参考层的分类和译义复核也继续保留为待办。
