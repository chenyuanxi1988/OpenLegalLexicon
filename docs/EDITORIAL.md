# 核心术语编审与法条证据

核心学习层目前含 **218 个**中国大陆法律语境词条，均标记 `evidence_linked`：首批 99 条覆盖民商、隐私、竞争和知识产权等领域，第二批 38 条覆盖行政处罚、行政复议和劳动合同，第三批 46 条覆盖增值税、关税、对外贸易及贸易救济，第四批 35 条覆盖刑法总则高频概念及刑法修正案（十二）相关公司/行贿重点。`evidence_linked` 表示释义和法域已对应到具体法条；不表示法律专家审核，也不将英文标为官方正式译文。词条由 Codex 辅助编写，署名及审核状态可逐条查看。

## 两个数据层

- 来源参考层保留两套官方双语表的 2,730 条来源对应。来源原文不静默改译，未经核实的法域留空。
- 核心学习层采用多个独立 `editorial_seed` 快照，保留稳定 ID、中文释义、译法说明、学习提示及关系。英文为项目释译；即使中文同形，也不自动合并不同法域或来源的词条。

`--profile learning` 筛选有释义与法条证据的词条。默认参考版同时包含两层，完整保留审核状态。简繁转换仅转换文字形式；中国大陆术语的繁体形式不因此变成台湾或香港法律术语。

第四批核心层新增 35 条，优先覆盖高频总则和修正案（十二）重点，而不是机械把 58 个证据条文全部变成词条。主要边界包括：

- 犯罪预备、犯罪未遂、犯罪中止分别按第二十二至二十四条保留不同成立条件。
- 共同犯罪、主犯、从犯、教唆犯和单位犯罪分开记录，避免把共同犯罪参与角色混成一个标签。
- 自首、立功、缓刑、撤销缓刑、追诉时效和不受追诉期限限制的情形分别记录法定条件。
- 修正案（十二）相关公司领域不使用泛化“民营企业腐败罪”标签，而分别记录第一百六十五、第一百六十六、第一百六十九条对应的主体、行为和损失条件。

## 编辑与复核

1. 新的原创批次建立独立 `data/snapshots/oll-cn-*.jsonl`，无需改写已发布批次；稳定 ID 表示固定概念记录，不因释义或拼写修订改变。
2. 释义、法域和学习提示分别声明 `evidence.supports`，以 `document_id` 与 `articles` 指向实际存在的证据条文。
3. 对新版本法条先登记官方 HTTPS 目标，保存公开原始 HTML 到独立缓存，记录获取日期及摘要，完整抽取并审查变化后再更新证据。不能只改条号而沿用旧释义。
4. 若引入新的资料或译文，先独立核验许可。法律中文原文的地位，不证明第三方译文可再分发。
5. 更新来源快照 SHA-256 和条目数，运行校验、单元测试与构建；CI 现在会在正式校验前打印所有快照实际 SHA-256，便于发现登记漂移，但摘要不一致仍会失败关闭。
6. 提交源码后由 CI 实际运行 schema、单元测试、可复现构建、Rime 编译查询以及 Anki 完整版/核心版真实导入与重复导入；只有远端运行和自动生成文件闭环后才记录为已发布。

离线核对已固定的 HTML 与证据，可使用：

```sh
python tools/verify_legal_sources.py --cache /path/to/legal-html --out build/legal-evidence-check.json
```

输出只证明抽取一致性，不证明英文准确或法律适用结论。

## 下一阶段编审重点

四批中国大陆核心学习层已经形成 218 条证据型词条，但来源参考层仍有 2,730 条来源对应，其中 1,467 条在自动规则下未分类，且尚未逐条完成法域与译义复核。下一阶段先按高频、机构/法规/缩写、核心领域和同形异义风险建立可审计编审批次；自动规则只用于生成候选队列，不把机器分类状态冒充人工审核完成。


## 来源参考层第三批：20 组同形词的 40 条原始记录

本批逐条对照摘要已核验的原始 HTML/CSV，比较前仅做既有 NFC 与空白归一化。补齐遗产、隐私权、住所、假处分、判例、上诉、异议等的类别与词形/语境说明；不补推法域、法条含义或官方法律效果。三批累计处理 57 条，55 条分类/说明复核、2 条隔离；所有 2,730 条来源译文仍保持 source_attributed。详细前后值和原文定位见 [编审报告](../reports/source-review-batch3-2026-09-12.json)。

- 司法院第 905 条“政府公报”原 HTML 确为 Government Official；对照商标快照第 378 条 Official Gazette，前者有词义不完整的疑点。保留原文并隔离，不静默补词。
- 商标第 451 条“申请期间”原 CSV 确为 prosecution of the application。[USPTO 的 TMEP 说明](https://www.uspto.gov/guidance)将 prosecution 用于申请办理和审查程序；这是本项目标记译义错位疑点的依据之一，不是对源机构意图或替代译文的最终认定。
- 假处分不因含“处分”就归入行政处罚；准用的拉丁语表达不标成首字母缩写；appeal、opposition、authentication、identification、justify 等保留原词形和程序语境，不能无条件互换。

quarantined 或 suspected_translation_error 记录默认不进入学习与输入法产物；原始快照仍保留，查询时可显式使用 --include-quarantined 查看说明。队列的 unresolved_quality_items 保存未解决事项，不以隔离状态充当复核完成。
