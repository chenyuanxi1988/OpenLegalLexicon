# Lexicon

这里存放 OpenLegalLexicon 的两个正式词典、冻结的迁移源和参考索引。

## 1. `us_legal_english.csv` — 主词典

**方向：English → 中文参考翻译**

**当前：25 条迁移种子。**

英文法律词条是 canonical headword。词条首先说明英文表达的法律/交易含义、法域和使用语境，再提供中文参考翻译和中文辅助说明。

本轮迁入的 25 条均来自旧词表中的跨境交易实务表达，当前统一标记：

- `适用法域 = INTERNATIONAL_TRANSACTIONAL`
- `审核状态 = migration_review`

这 25 条只是 English-first 的迁移种子，并未因为常见于跨境交易就直接标记为 `US`。后续应逐条以美国法、美国交易文件和美国权威实务来源复核，必要时再修改法域和审核状态。

正式美国法词条推荐法域标签包括：

- `US`
- `US-FEDERAL`
- 具体州法标签
- `INTERNATIONAL_TRANSACTIONAL`（仅限确有美国律师实务价值的国际交易表达）

## 2. `chinese_legal_terms.csv` — 中文法律词典

**方向：中文 → English reference translation**

**当前：392 条迁移记录。**

中文是 canonical headword。为避免项目改向时丢失原有编审成果，本轮将冻结旧词表中的 392 条中文主词条全部迁入本文件。

这些记录：

- 绝大多数属于中国大陆法律制度词；
- 少量属于跨境交易中的中文实务表达，例如“交割”“尽职调查”“条款清单”等；
- 保留国际交易中文表达是为了中文检索和双向查找，不表示它们属于中国法法定概念；
- 中国法记录继续以中国法律依据和中国法语境为核心；
- 英文仅作为参考译法，不构成与美国法概念的自动对应。

### 当前兼容字段

为了无损迁移，当前暂时保留旧词表的 17 个字段，而不是在迁移时强制删减信息：

- 中文
- 繁體
- 英文
- 拼音
- 领域
- 适用法域
- 来源地区
- 类型
- 来源语境
- 学习注释
- 来源记录
- 条目ID
- 数据许可
- 译文审核
- 中文释义
- 译法说明
- 法律依据

以后如确有维护价值，可以在不丢失信息的前提下再统一 schema；目前不为了形式整齐而删除已有来源、学习提示或审核信息。

## 3. `legal_terms.csv` — 冻结的旧迁移源

**现有 392 条。**

这是项目改向前形成的旧混合词表。从 2026-09-30 起冻结：

- 不再新增；
- 不再作为主词典；
- 作为迁移审计和历史核对来源保留；
- 当前 392 条已经完整迁入 `chinese_legal_terms.csv`；
- 其中 25 条国际交易英语已经重新整理为 English-first 记录并进入 `us_legal_english.csv`。

在确认后续迁移和审计完全稳定前，不删除该旧文件。

## 4. `oxford_dictionary_of_law_10e_reference.md` — 候选词参考索引

该文件用于发现英文法律词候选、缩写和交叉参照，不是主词典，也不是美国法权威来源。

Oxford 候选词必须先判断是否适用于美国法，并以美国权威来源独立编写释义，才能进入 `us_legal_english.csv`。
