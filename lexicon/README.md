# Lexicon

这里是 OpenLegalLexicon 的核心内容。

## 文件

- `core_terms.csv`：332 条重点编审的中国大陆法律核心词语/词组，是未来开发主线。
- `legal_terms.csv`：3,055 条当前可直接使用的总词表，包含核心词和公开来源参考词。

## 重要字段

- **中文 / 繁體 / 英文**：词形
- **领域**：法律领域
- **适用法域**：如 CN；“待核查”表示不能仅由来源推断
- **类型**：term / action / role / document / institution 等
- **译文审核**：
  - `project_authored`：项目编审英文
  - `source_attributed`：保留第三方来源原译文，尚未独立确认
- **中文释义 / 学习注释 / 译法说明**：核心词条的必要语境
- **法律依据**：核心词条尽量保留具体法律、条文和链接

## 编辑原则

新增词条优先加入 `core_terms.csv`。

不要因为追求数量而把普通英语、重复词形或无法确认的翻译塞进核心词表。每批扩充重点应是律师实际使用的法律术语和固定搭配。
