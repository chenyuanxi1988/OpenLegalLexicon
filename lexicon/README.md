# Lexicon

这里是 OpenLegalLexicon 的全部词语数据。

## 1. legal_terms.csv — 主词库

**当前 392 条。**

这是项目真正要建设的中英文法律词库，也是以后唯一用于衡量“核心词量”的文件。

这些词条由项目独立编审，尽量包含法律语境、法域、释义、译法说明和法律依据。未来所有新增高价值词语和法律词组优先进入这个文件。

2026-09-29 已加入第一批 60 条公司治理、并购/股权投资交易文件、证券资本市场词语。中国法制度词尽量关联现行法律或监管规则；SPA、SHA、交割、陈述与保证等交易实务词明确标为项目编审的跨境交易表达，不冒充中国法法定术语或官方译文。

## 2. taiwan_reference_terms.csv — 台湾参考词表

**当前 2,723 条。**

来源于台湾司法院和台湾智慧财产局公开双语词汇，许可为 OGDL-Taiwan-1.0。

它的作用只是：

- 发现候选词；
- 对比既有译法；
- 找同形异义或专业领域漏词；
- 为主词库扩充提供线索。

**它不是 OpenLegalLexicon 的核心成果，不计入主词库数量，也不能因来源地区而推断词条都适用于台湾，更不能直接当作中国大陆法律译法。**

## 重要字段

- 中文 / 繁體 / 英文
- 领域
- 适用法域
- 类型
- 译文审核
- 中文释义
- 学习注释
- 译法说明
- 法律依据

以后应尽量减少重复文件，不再另外维护一份与主词库内容重复的 core_terms.csv。
